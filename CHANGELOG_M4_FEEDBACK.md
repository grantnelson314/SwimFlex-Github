# M4 Feedback Refinement

This revision intentionally avoids feature expansion. It addresses the four targeted issues identified from M4 feedback before the prototype is frozen for M5 testing.

## 1. Home-screen Adapt Workout clarity

- `Adapt Workout` no longer silently chooses the currently selected/first workout.
- It now opens **Choose a workout to adapt**.
- Selecting a workout continues to the existing Review Workout screen so the swimmer can confirm the Priority Set before adapting.

## 2. Original vs adjusted comparison

- Proposed Changes now labels the detailed section **Original vs adjusted, set by set**.
- Every set shows explicit **Original** and **Adjusted** rows, including notation and distance.
- The existing overall distance/time comparison and rationale remain unchanged.

## 3. SwimFlex branding/polish

- Added a compact SwimFlex wave identity on the home screen.
- Added the tagline **Adaptive swim workouts** and clearer home-screen explanatory copy.
- Existing color palette, typography, card system, and favicon are preserved so this remains a prototype rather than a visual redesign.

## 4. Pool/watch information hierarchy

Phone Pool Mode now emphasizes, in order:

1. what to swim now;
2. interval and next send-off;
3. rep progress;
4. set/focus label;
5. elapsed time and upcoming work as secondary information.

The simulated watch follows the same hierarchy, with the current swim and next send-off most prominent.
